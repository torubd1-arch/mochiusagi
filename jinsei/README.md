# 人生コレクション100

人生で「これからやりたいこと」と「これまでに経験したこと」をコレクションする個人用 Web アプリ。件数の上限・達成率・期限はなく、登録する楽しさと振り返る楽しさを重視しています。サーバー・ログイン不要で、項目と写真は端末の IndexedDB に保存します。

## 起動方法

ES モジュールと Service Worker を使うため、`index.html` を直接開かず、HTTP サーバー経由で開きます。

```sh
cd jinsei
npm run serve   # http://localhost:8080 で確認
npm test        # ロジック・ZIP のテスト（Node 20 以上）
```

## GitHub Pages での公開

`main` へマージすると `https://<ユーザー名>.github.io/<リポジトリ名>/jinsei/` に反映されます。

配信ファイルを変更したら `sw.js` の `CACHE_VERSION` を上げてください（上げないと端末に反映されません）。

## iPhone のホーム画面に追加

Safari で上記の URL を開き、共有ボタン →「ホーム画面に追加」。

- Safari とホーム画面のアプリでは保存先が別です。最初からホーム画面のアプリで使ってください
- ホーム画面のアプリの削除や、Safari の「履歴とWebサイトデータを消去」でデータは消えます。設定画面から定期的にバックアップ（ZIP）を「ファイル」アプリや iCloud Drive に保存してください

## 画面

- やりたいこと … 1行1項目のリスト。★、検索、カテゴリ絞り込み、ランダムに1件引くガチャ
- 思い出 … 写真付き2列カード。年表表示に切り替え可能
- すべて … 未達成・達成済み・保管中を横断して検索
- 保管中 … 興味がなくなった項目（削除せずに一覧から外したもの）。復帰できる
- 設定・バックアップ … 件数、写真枚数、ストレージ使用量、ZIP バックアップ・復元

## 構成

- `index.html` / `css/style.css` … 画面
- `js/logic.js` … 項目の検証・更新、曖昧な日付、検索・並び順・年表、バックアップ検証・統合方針の純粋ロジック（テスト対象）
- `js/zip.js` … ZIP の書き出し（無圧縮）と読み込み（無圧縮・deflate）。外部ライブラリなし（テスト対象）
- `js/store.js` … IndexedDB の読み書き
- `js/photo.js` … 写真の縮小・JPEG 圧縮、サムネイル作成
- `js/app.js` … 描画と操作
- `sw.js` / `manifest.webmanifest` / `icons/` … ホーム画面追加・オフライン用

## データ形式

IndexedDB `jinsei-collection` のストア:

| ストア | 中身 |
| --- | --- |
| `items` | 項目（下記） |
| `photos` | 写真の情報とサムネイル `{ id, itemId, type, width, height, thumbType, thumb: ArrayBuffer }` |
| `photoData` | 写真の本体 `{ id, data: ArrayBuffer }`（一覧でサムネイルだけ読むため分けている） |
| `meta` | `lastBackupAt` / `lastChangeAt` / `snoozeUntil` |

```json
{
  "id": "…",
  "title": "オーロラを見る",
  "kind": "done",
  "category": "travel",
  "favorite": true,
  "archived": false,
  "note": "感想・メモ",
  "date": "2024-02",
  "photoIds": ["…", "…"],
  "createdAt": "2026-11-01T00:00:00.000Z",
  "updatedAt": "2026-11-01T00:00:00.000Z"
}
```

- `kind` … `wish`（これからやりたい） / `done`（経験した）
- `date` … `2024-02-03`（年月日） / `2024-02`（年月） / `2024`（年） / `1990s`（年代） / `""`（なし）
- `photoIds` … 写真の並び順。先頭が代表写真
- 写真は長辺 1600px・サムネイルは長辺 480px の JPEG に縮小して保存

バックアップ ZIP の中身は `data.json`（項目と写真の一覧）、`photos/<id>.jpg`、`thumbs/<id>.jpg`。

## 安全のための決まり

- 画面への表示は `textContent` のみ（入力内容を HTML として解釈しない）
- 1回の操作（項目と写真の追加・削除）は1つのトランザクションで書く。失敗したら何も変わらない
- 保存に失敗したら警告し、画面の状態と入力中の内容はそのまま残す
- 写真は端末内だけで処理し、サーバーには送らない
- 復元は data.json と写真ファイルをすべて検証してから書き込む。1か所でも不正があればファイル全体を拒否する
- 復元時は「統合（同じ項目は更新日時が新しい方を残す）」か「置き換え」を選ぶ。置き換えは二重に確認する
- 保存データの中に読めない項目があっても、DB からは消さずに残す
