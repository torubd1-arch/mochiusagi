# ショートアプローチ30

5・10・15・20・25・30・40・50ヤードのアプローチを1球ずつ ○（成功）／△（惜しい）／×（失敗）で記録し、成功率とトップ率を確認する練習アプリ。サーバー・ログイン不要で、データは端末の localStorage に保存します。

## 起動方法

ES モジュールと Service Worker を使うため、`index.html` を直接開かず、HTTP サーバー経由で開きます。

```sh
cd approach
npm run serve   # http://localhost:8080 で確認
npm test        # 出題・判定・集計・保存のテスト（Node 20 以上）
```

## GitHub Pages での公開

`main` へマージすると `https://<ユーザー名>.github.io/<リポジトリ名>/approach/` に反映されます。

配信ファイルを変更したら `sw.js` の `CACHE_VERSION` を上げてください（上げないと端末に反映されません）。

## iPhone のホーム画面に追加

Safari で上記の URL を開き、共有ボタン →「ホーム画面に追加」。一度開けば、以降はオフラインでも練習・記録・履歴閲覧ができます。

- Safari とホーム画面のアプリでは保存先が別です。最初からホーム画面のアプリで使ってください
- Safari の Web サイトデータ消去やホーム画面のアプリ削除で記録も消えます（履歴画面にも注意書きを表示）

## 構成

- `index.html` / `css/style.css` … 画面（ホーム・練習中／ミス原因・結果・履歴の4画面を1ページで切り替え）
- `js/logic.js` … 出題・判定・集計の純粋ロジック（テスト対象）
- `js/store.js` … localStorage の読み書き（テスト対象）
- `js/app.js` … 描画と操作
- `sw.js` / `manifest.json` / `icons/` … ホーム画面追加・オフライン用
- `tests/` … `node --test` で実行する自動テスト

## 仕様の要点

- 出題（ランダム）：各距離の回数差は最大1回。同じ距離の連続は回数を崩さない範囲で避ける。開始時に全出題順を確定し、「1球戻る」でも変えない
- 判定：○ はそのまま次の球へ。△× はミス原因を1つ選ぶ（トップは × のみ）
- 二重タップ：判定・ミス原因・1球戻るは 0.45 秒以内の連続タップを無視する
- 集計：成功率＝○÷総球数、トップ率＝トップ÷総球数、その他ミス率＝トップ以外のミス原因（△を含む）÷総球数。小数第1位まで、0球は「—」
- 途中終了：打球済みの球を「途中終了」として履歴に残し、参考成績として表示する。全体集計・成績推移には含めない。1球も打っていなければ履歴に残さない
- 保存：1球ごとに即時保存。保存に失敗したら画面を進めず、エラーを表示する

## 保存データ

キーごとに `{ "version": 1, "data": … }` の形で保存します（`version` はスキーマバージョン）。

| キー | 内容 |
|---|---|
| `approach30.settings` | 最後に使った設定（モード・球数・クラブ・ランダム距離・固定距離） |
| `approach30.history` | 完了・途中終了したセッションの配列 |
| `approach30.active` | 練習中のセッション（同時に1つだけ） |

読めなかったデータは `<キー>.broken` に元の文字列を残してから起動します。

セッションの形式：

```json
{
  "id": "s-…",
  "startedAt": "2026-11-17T10:00:00.000Z",
  "endedAt": "2026-11-17T10:20:00.000Z",
  "status": "completed",
  "mode": "random",
  "club": "SW",
  "totalShots": 30,
  "selectedDistances": [10, 15, 20],
  "distanceSequence": [15, 10, 20, "…全30球分"],
  "shots": [
    { "shotNumber": 1, "targetDistance": 15, "club": "SW", "mode": "random", "result": "success", "missType": null }
  ]
}
```

- `status`：`active` / `completed` / `aborted`
- `result`：`success`（○）/ `near`（△）/ `failure`（×）
- `missType`：`top` / `duff` / `short` / `over` / `other` / `null`（○のとき）
- 球ごとに `club` と `mode` を持つので、将来の球ごとのクラブ変更やモード別集計にそのまま使えます
