
やりとり難易度の表は、自動プレイヤー（ボット）で各魚種 200 回ずつ試した結果です。

| 列 | ボットの操作 |
|---|---|
| perfect | 反応の遅れなし。暴れていないときだけ、張りが 0.6 未満なら巻く |
| slow | 反応が 0.25 秒遅れる（人間程度）。張り 0.5 未満で巻く（控えめ） |
| greedy0.7 / 0.8 | 反応 0.25 秒遅れ。張り 0.7 / 0.8 未満まで巻く（欲張り） |
| time | perfect で釣り上げるまでの平均時間 |

- 控えめに操作すれば、人間程度の反応でもどの魚も釣れる
- 欲張って巻くと、レアな魚ほど糸が切れやすい（ニシキゴイ → オオナマズ → 黄金の魚）
- 押しっぱなしで釣れるのはメダカ（と長靴）だけ。ブラックバス以上は、暴れている最中に巻き続けると糸が切れる（`test_fight_basic`）

ボットは人間の操作を単純化したものなので、実際の手応えは実機で確認して `FIGHT_PARAMS` を調整してください。

## 4. PC プレビューで確認したこと

`tools/preview` で `main.c` の描画処理を PC 上で実行し、タイトル・狙い中・キャスト中・食いつき待ち・HIT・釣果（全 9 種）・黄金の魚・失敗・残り 10 秒以下・一時停止・TIME UP・結果の各場面を PNG にして確認しました。

- 文字のはみ出し、要素の重なり、魚イラストの崩れを確認し、見つかった問題（太陽が SCORE 欄に隠れる、オオナマズの輪郭線、釣果カード見出しの角）は修正済み
- フェイント：ウキが沈みしぶきが出るが HIT! が出ない場面を確認
- やりとり：開始（ファイト！）、暴れる予兆（「！」）、暴れ中（しぶき・赤い警告）、巻き上げ途中、糸が切れた場面を確認
- 1 フレームあたりの描画量は最大で約 4,000 三角形・約 400 文字（`C2D_Init(16000)` の上限に対して十分余裕あり）

ただし、プレビューの文字は PC のフォントで代用しており、3DS 内蔵フォントの字幅とは異なります。最終的な見た目は実機で確認してください。
