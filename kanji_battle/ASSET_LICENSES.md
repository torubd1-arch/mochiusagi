# ASSET_LICENSES

かんじバトルで使用している素材・データの出典台帳です。新しい素材を追加する
ときは、このファイルに行を追加してください。「取得元URL」と「ライセンス」が
両方埋まらないうちは、素材ファイルをコミットしないことを推奨します。

判定の見方: **可** = 商用利用・同梱に問題ない / **要確認** = 追加確認が必要 /
**不明** = 現時点で根拠が確認できていない。

## 備考

- 応援キャラクター3体(くまさん/ペンペン/オオサンショウウオ)の「商用利用: 要確認」は、
  生成AIでイラスト化する際に参照したユーザー私物のぬいぐるみそのものの商品名・
  メーカーが未確認であるため。実物の意匠を強く連想させる場合、意匠権・著作権上の
  リスクが残る可能性がある。詳細は監査レポートを参照。
- 台帳の更新ルール: 新しい素材(画像・音源・フォント・外部データ等)を追加するときは、
  必ずこの表に1行追加し、「取得元URL」「ライセンス」を確認できるまではコミットしない。
