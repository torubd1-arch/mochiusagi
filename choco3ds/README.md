# チョコキャッチ！ 3DS版

Web版（[choco/index.html](../choco/index.html)）を、ニンテンドー3DSの自作ソフト（homebrew, `.3dsx`）として移植したものです。
旧3DS / 2DS で動くことを前提にしています。

## ゲーム仕様（Web版と同じ）

- 制限時間 30秒（のこり5秒でBGMが速くなる）
- 茶チョコ +1点 / 紫チョコ +2点 / 帽子・持ち物 +3点
- レア（8%）とその日のラッキーアイテムは得点2倍（両方なら4倍）
- ダンベルに当たると 1.5秒動けない
- 図鑑：帽子90種＋持ち物90種
- ラッキーアイテムはWeb版と同じ計算なので、同じ日なら同じアイテムになる

## 3DS版で変えたところ

| 項目 | Web版 | 3DS版 |
|---|---|---|
| 画面 | 1画面 800×600 | 上画面にゲーム、下画面にスコア・時間・ボタン |
| フィールドの高さ | 600 | 480（論理座標）。アイテムがプレイヤーに届くまでの時間がWeb版と同じになるよう落下速度を補正 |
| 図鑑 | 30件×3ページ | 18件×5ページ（画面が小さいため） |
| 絵文字 | 🍫👑⚡ など | 3DS本体のフォントに無いため、図形や ★☆ に置き換え |
| 保存先 | ブラウザの localStorage | SDカード `sdmc:/3ds/chococatch/save.bin`（Web版のデータは引き継げない） |
| 保存するタイミング | アイテムを取るたび | ゲーム開始時・終了時・アプリ終了時（プレイ中にSDカードへ書き込んで動きが止まらないようにするため） |

## 操作

| 画面 | ボタン | タッチ（下画面） |
|---|---|---|
| タイトル | A：スタート / X：図鑑 / ←→：キャラ選択 / START：アプリ終了 | 各ボタン（それ以外の場所をタッチしてもスタート） |
| プレイ中 | 十字キー・スライドパッド ←→：移動 | 左右の大きなボタン |
| 結果 | A：もういちど / X：図鑑 | 各ボタン |
| 図鑑 | L/R：タブ切り替え / ←→：ページ / B：もどる | 各ボタン |
| どこでも | SELECT：音のON/OFF | 右上の Sound ボタン |

## ビルド方法

このPCでは Windows のスマートアプリコントロールが devkitPro のコンパイラを止めるため、WSL の Ubuntu でビルドします
（Ubuntu には devkitPro と `3ds-dev` を導入済み）。PowerShell で次を実行すると `chococatch.3dsx` ができます。

```powershell
wsl -d Ubuntu -u root -- bash -c "source /etc/profile.d/devkit-env.sh && cd /mnt/c/mycode/mochiusagi/choco3ds && make"
```

作り直すときは `make` の前に `make clean` を実行します。

## 3DSでの遊び方

1. CFW（Luma3DS など）と Homebrew Launcher が使える3DSを用意する
2. `chococatch.3dsx` を SDカードの `/3ds/` フォルダにコピーする
3. Homebrew Launcher から起動する

音を出すには、SDカードに `/3ds/dspfirm.cdc` が必要です（CFW導入時に DSP1 で作成するのが一般的です）。
無い場合も、音が鳴らないだけでゲームは遊べます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `source/main.c` | ゲームの状態管理・更新・画面描画・入力 |
| `source/icons.c` | 帽子18種・持ち物18種のアイコン描画 |
| `source/draw.c` | Canvas 2D と同じ感覚で使える描画関数（citro2d の三角形描画で実装） |
| `source/audio.c` | BGM・効果音の音源（矩形波・三角波を合成） |
| `source/save.c` | セーブデータの読み書き |
| `source/data.c` | 色・アイテム名などのデータ |
