# 川西モルック検定 記録ツール（Ver.1.0）

「川西モルック検定」のお題（配置図）を表示し、1〜4人の投球結果（○×）を1台のスマートフォンで記録するWebアプリです。ログイン・サーバー不要で、記録は端末のブラウザ内（localStorage）に保存されます。アプリの合格表示は入力結果の集計で、主催者への申請・認定は行いません。

## 構成

既存の「モルとも」（`../molkky/`）に合わせ、**依存ライブラリなしのES Modules（素のJavaScript）・ビルド不要** で実装しています。

| ファイル | 役割 |
| --- | --- |
| `js/grades.js` | 12級〜1級のお題データ（名称・距離・成功条件・注記）と、元画像からの配置図の切り出し位置 |
| `js/logic.js` | 手番・合否・個別終了・訂正・取り消し・保存データ検証（UIから独立した純粋関数） |
| `js/storage.js` | localStorage への保存・読込（保存できない環境でも例外を出さない） |
| `js/app.js` | 画面の描画と操作 |
| `img/kentei-source.jpg` | お題の元資料（川西モルックの会「川西モルック検定」資料 IMG_3192.jpeg） |
| `tests/` | ロジックの自動テスト（`node:test`） |

## 起動

ES Modules を使うため、`file://` ではなくHTTPサーバー経由で開いてください。

```sh
cd kentei
npm run serve        # http://localhost:8081/ （npx で http-server を一時利用）
```

GitHub Pages では `https://<ユーザー>.github.io/mochiusagi/kentei/` で公開されます（トップページにもカードを追加済み）。

## テスト

Node.js 20 以上（追加パッケージ不要）。

```sh
cd kentei
npm test
```

お題データの並び、開始設定、手番の巡回、合否、個別終了（表示条件・スキップ・全員終了）、ひとつ戻す、訂正による合否の再計算と終了解除、連打の無視、保存データの検証を確認します（仕様書8章の項目のうちロジック部分）。

## 配置図

元資料の画像1枚を同梱し、各級の図の範囲を CSS の `background-position` で切り出して表示しています（`grades.js` の `crop`）。図の描き直しはしていないため、ピン配置・距離線・間隔の注記は元資料のままです。タップで拡大表示します。

## 仕様書の「初期実装の前提」からの変更・補完

| 項目 | 内容 |
| --- | --- |
| 連打対策 | ○×・終了の入力時に「表示していた本人と投球数」を照合し、食い違う入力は無視する。加えて入力後 0.45 秒はボタンを無効にし、「→ 次は○○さん」と表示する |
| ひとつ戻す | 直前1回だけでなく、最大200操作まで順にさかのぼれる。取り消し履歴も端末に保存し、再読み込み後も戻せる。新しい挑戦を始めると履歴は消える |
| 記録中の訂正 | 記録画面では記録済みの○×をいつでもタップで訂正できる。結果画面では「記録を訂正」を押してから訂正する |
| 人数・級の変更 | 記録画面の「人数・級の変更」から開始設定へ移る（名前・人数・級を引き継ぐ）。開始時に置き換えの確認を出す。「記録に戻る」で取りやめられる |
| オフライン | Service Worker（PWA）は初版では入れていない。一度開いたページは開いたままなら電波がなくても記録できる |
