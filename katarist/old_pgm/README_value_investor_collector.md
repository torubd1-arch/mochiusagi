# バリュー投資家の「買い理由」収集スクリプト

指定した日本株について、Web検索結果から個人投資家のブログ・note・X検索結果などを探し、
「なぜ買ったか」「何が割安か」「カタリストは何か」「下値は何で支えられるか」
といった記述を短い原文抜粋とURL付きで一覧化します。

## 1. インストール

Python 3.10以上を推奨します。

```bash
pip install -r requirements_value_investor_collector.txt
```

## 2. 実行例

```bash
python value_investor_thesis_collector.py --code 4628 --name "エスケー化研"
```

結果は `output` フォルダに以下の2ファイルで保存されます。

- `4628_エスケー化研_investor_views.csv`
- `4628_エスケー化研_investor_views.md`

## 3. 検索を増やす例

```bash
python value_investor_thesis_collector.py ^
  --code 4628 ^
  --name "エスケー化研" ^
  --extra-query "\"{name}\" 株 値上げ 利益率" ^
  --extra-query "\"{name}\" 株 資本政策"
```

Windows PowerShellなら `^` ではなくバッククォート `` ` `` を使うか、1行で実行してください。

## 4. 出力項目

- score: 「買い理由」「割安性」「カタリスト」等のキーワードを基にした探索優先度
- source_type: ブログ / note / X / 市場情報・メディア / Web
- actual_buy_signal: 「買いました」「買い増し」等の実購入表現が見つかったか
- matched_categories: 割安性、下値・財務、株主還元、資本配分、カタリスト等
- evidence_excerpt: 原文の短い抜粋
- url: 必ず原文確認するためのリンク
- search_queries: そのページを発見した検索語
- fetch_status: 本文取得状況

## 5. この設計の意図

このスクリプトは「正しい投資判断」を出しません。
目的は、ChatGPT等に最初から結論を聞く前に、他の投資家が見ている論点を広く集めることです。

特に次の見落とし防止を狙っています。

- 低PER/PBR以外の割安理由
- ネットキャッシュ・資産価値など下値材料
- 値上げ、M&A、事業売却、政策保有株売却、還元強化
- 不採算事業の整理、構造改革
- 親子上場、TOB/MBO、アクティビスト
- 中計変更、資本コスト/PBR1倍対応
- 一過性利益やシクリカルなどの反対材料

## 6. 制約

- 検索エンジン側の仕様変更で検索結果が変わる場合があります。
- Xは本文取得が難しいため、原則として検索結果のスニペットを利用します。
- JavaScript必須サイト、ログイン必須サイト、ペイウォールは取得できないことがあります。
- CAPTCHAやアクセス制限の回避は行いません。
- スコアは「読む順番」を決めるためのものです。投資判断の点数ではありません。
